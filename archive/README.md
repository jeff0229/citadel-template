# archive/

Kept originals: immutable, complete, cheap to add to, searchable by full text. This layer holds artefacts, not knowledge. An un-promoted artefact is not a failure; the archive may be large and boring so that `wiki/` can stay small and true.

| Folder | Holds |
|---|---|
| `chats/` | Exported LLM conversations, one file per conversation |
| `web/` | Saved articles and pages as markdown, with the source URL and retrieval date |
| `code/` | Snippets and snapshots kept outside a repo; never a mirror of a live repo |
| `notes-md/` | Markdown imported from other vaults, apps or exports |
| `media/` | Transcripts of talks, videos and audio, with the link and duration |
| `../raw/` | The PDF wing: papers, books, reports, one subfolder per topic |

1. **Contents are immutable.** Fix an error by writing a wiki page that records the correction, never by editing the artefact.
2. **Filenames carry the date and a readable title:** `2026-01-01 - claude - library architecture.md`.
3. **Binaries stay out unless irreplaceable.** Video and audio are archived as a transcript plus a link.
