# inbox/

Drop zone. Anything lands here in any format, unsorted and unnamed: chat exports, markdown, code, screenshots, links in a text file, PDFs. Nothing in here is knowledge yet.

1. **Drop and forget.** No naming convention, no frontmatter, no folder choice required.
2. **The librarian empties it.** On request or at session start, everything is triaged into `archive/` (kept, dated, titled, domain-tagged) or `raw/` (PDFs), or flagged for deletion. Nothing is deleted without asking.
3. **The inbox is not storage.** A file that survives two triage passes is archived or discarded.
